# Security Policy

## Scope

Nano-Stream is a research-oriented software project involving network traffic
classification and Software-Defined Networking (SDN)-based traffic
enforcement.

Security issues involving the repository, implementation, dependencies, or
deployment behavior should be reported responsibly.

## Reporting a Vulnerability

Please do not publicly disclose a suspected security vulnerability through a
GitHub issue before giving the maintainer an opportunity to investigate it.

For security-sensitive reports, contact the repository maintainer privately
through the contact information associated with the GitHub profile.

A useful security report should include:

- a clear description of the vulnerability
- affected file(s) or component(s)
- steps to reproduce
- potential impact
- relevant logs or proof-of-concept information, where safe to provide

## Do Not Publicly Disclose Sensitive Information

Do not publicly post:

- passwords or credentials
- API keys or tokens
- private network information
- personal information
- secrets contained in configuration files
- sensitive exploit information when private disclosure is more appropriate

## Dependency Security

Nano-Stream depends on third-party Python packages and networking software.

Users should review dependency versions and relevant security advisories
before deploying the project in a production environment.

## Research Disclaimer

Nano-Stream is a research implementation.

The repository should not automatically be considered production-ready network
security infrastructure without additional security validation, testing,
monitoring, and operational hardening.
